# Changelog

## Unreleased

### 1.1.0 candidate

- Add Circle profile Sides (3–1024, default 32) and independent Roll (default 0°).
- Add a one-step upgrade for older profiles while preserving their existing dimensions and Rectangle Roll.
- Add shaded boxes to the drawing and editing sidebar panels; the shade follows Blender's theme.
- Expand drawing and editing instructions on GitHub and the Blender Extensions listing. Add supported Add Curve, Modeling, and 3D View manifest tags.
- Background checks passed on Blender 5.2.5 LTS for Windows. Owner acceptance and public release remain pending.

- Add a release preparation command and automatic upload of tested stable GitHub release assets to the existing Blender Extensions Spline listing.
- Document versioning, owner acceptance, account setup, upload recovery, and verification of updates through Blender.

## 1.0.0 — 2026-11-22

- Publish Spline by Pease Technology under GPL-3.0-or-later, with native Bézier drawing and editing, topology tools, and live Rectangle/Circle profiles.
- Recorded validation targets Blender 5.2.4 LTS for Windows with Default and Industry Compatible keymaps; see `docs/TEST_PLAN.md` for scope and limitations.
