# Spline 1.1.0

Circle profiles now offer polygon sides and their own roll angle, and the Spline sidebar has a darker shaded background.

- **Circle Sides:** choose 3–1024 edges around the cross-section; default 32. Use low counts for triangular/square profiles and 100/128 or higher for a rounder sweep. Radius measures from the center to each corner.
- **Circle Roll:** rotate the cross-section about the path in degrees; default 0°. Circle and Rectangle remember independent roll values. Curve Resolution still controls sampling along the path.
- **Older profiles:** click **Update Profile** in Object Mode to expose the new controls while preserving Shape, Height, Width, Radius, and Rectangle Roll. The upgrade is undoable; existing source curves remain native Bézier data.
- **Clearer sidebar:** Object Mode and Edit Spline controls use darker shaded boxes with Blender Dark; the exact shade follows the active Blender theme.
- **Getting started:** expanded drawing instructions and the editing hotkey reference are available on GitHub and Blender Extensions. Discovery tags now include **Add Curve**, **Modeling**, and **3D View**.

To start drawing, choose **Object Mode → Add → Curve → Draw Spline**. Select a Bézier curve and press **6** to edit; **1/2/3** choose Vertex/Segment/Spline, **Q/W/E/R** choose Select/Move/Rotate/Scale, and **4** or **Enter** returns to Object Mode. The sidebar exposes the same actions.

The owner accepted this build on November 27, 2026. The full background suite and selected viewport checks passed on **Blender 5.2.5 LTS for Windows**. The existing 1.0.0 baseline was tested on Blender 5.2.4 LTS with Default and Industry Compatible keymaps; the new controls have not been independently checked on 5.2.4 or every keymap/theme combination. Tight or intersecting profile sweeps can still overlap.
